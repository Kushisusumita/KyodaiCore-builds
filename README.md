# KyodaiCore: сборки

Готовые сборки игры (trikz на Unreal Engine 5) для автообновления. Исходники здесь не лежат.

## Установка с нуля

1. Скачать [KyodaiCore-launcher.zip](https://github.com/Kushisusumita/KyodaiCore-builds/releases/latest/download/KyodaiCore-launcher.zip)
   и распаковать в пустую папку.
2. Запустить `Join.bat`: он скачает всю игру (около 1,4 ГБ) и спросит адрес хоста.

## Как работают обновления

Каждый релиз содержит `manifest.json`: список всех файлов игры с размером, SHA-256 и ссылкой на
скачивание. `Host.bat`, `HostIP.bat` и `Join.bat` перед запуском игры сверяют с ним файлы в своей папке и
скачивают только изменившиеся. Каждый скачанный файл проверяется по хешу. Папку `Saved` (настройки,
записи, логи) обновление не трогает.
