# KyodaiCore: сборки

Готовые сборки игры (trikz на Unreal Engine 5) для автообновления. Исходники здесь не лежат.

Каждый релиз содержит `manifest.json`: это список всех файлов игры с размером и SHA-256 и ссылками на них.
`Host.bat`, `HostIP.bat` и `Join.bat` перед запуском игры сверяют с этим списком файлы в своей папке и
скачивают только изменившиеся. Скачанный файл проверяется по хешу, папку `Saved` (настройки, записи,
логи) обновление не трогает.

Как установить игру с нуля: скачать из последнего релиза `Host.bat`, `HostIP.bat`, `Join.bat`,
`Play.ps1` и `Update.ps1` (это файлы с хешем в начале имени: переименовать, убрав хеш и дефис) в пустую
папку и запустить `Join.bat`. Он скачает всю игру.
